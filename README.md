# LearnLoop

แพลตฟอร์มเรียนและฝึกทำโจทย์ภาษาไทยสำหรับนักศึกษา สร้างด้วย Next.js App Router, React, TypeScript และ Tailwind CSS รายวิชา ITDS120 มี 5 บทเตรียมไฟนอลและแบบฝึกเขียนโปรแกรม 50 ข้อ รายวิชา ITDS113 เปิดข้อสอบปรนัยเตรียมไฟนอล 6 บท รวมเป็นชุดเดียว 50 ข้อ ใช้เวลา 100 นาที

## เปิดใช้งานบนเครื่อง

ใช้ Node.js 22 ขึ้นไปและ npm เปิดเทอร์มินัลในโฟลเดอร์โปรเจกต์แล้วรัน

```sh
npm ci
npm run dev
```

เปิด [LearnLoop บนเครื่อง](http://localhost:3000) สคริปต์เตรียมไฟล์ของ Monaco Editor ให้อัตโนมัติ เว็บโหลดฟอนต์และภาพประกอบจากไฟล์ของโปรเจกต์

## สร้างเว็บสำหรับเผยแพร่

```sh
npm run build
npm run typecheck
npm start
```

ไฟล์เว็บอยู่ใน `out/` ใช้กับโฮสต์แบบสแตติกที่รองรับไฟล์ index ในแต่ละไดเรกทอรีได้ คำสั่งสุดท้ายจะแสดงที่อยู่สำหรับดูตัวอย่าง

## ทดลองใช้งาน

- เริ่มที่ `/courses/itds120` เพื่อเลือกบท หรือเปิด `/practice/dict-key` เพื่อทำโจทย์แรก
- ในตัวแก้ไขโค้ด กด Ctrl/Cmd + Enter เพื่อทดสอบ หรือ Ctrl/Cmd + Shift + Enter เพื่อส่งคำตอบ เปิดคำใบ้หรือเฉลยได้ในแผงโจทย์
- ทำโจทย์สำเร็จเพื่อรับ XP หนึ่งครั้งต่อข้อ ดูความก้าวหน้า เหรียญรางวัล และโจทย์แนะนำได้ในหน้าภาพรวมการเรียน
- ที่ `/exams` มีข้อสอบเตรียมไฟนอล ITDS120 เวลา 60 นาที ครอบคลุม Dictionary, Function, File I/O, NumPy และ Pandas หัวข้อละ 4 ข้อ รวม 20 ข้อ ระบบจำคำตอบและเวลาสิ้นสุดแม้โหลดหน้าใหม่ หลังส่งข้อสอบจะดูผลและทบทวนทีละข้อได้
- บัญชีอีเมลใช้ Supabase Auth และบันทึกผลงานลง learning_records ตามบัญชีด้วย RLS ผู้เรียนรับเชิญเก็บผลงานบนเครื่องและเลือกนำเข้าได้ในหน้าโปรไฟล์ สำหรับโปรเจกต์ Supabase ใหม่ ให้รัน supabase/migrations/202611170001_learning_records.sql ก่อน
- เปิด Email provider และ Confirm email ใน Supabase Auth ตั้ง Site URL เป็นโดเมนเว็บจริงและเพิ่ม URL สำหรับกลับเข้าเว็บหลังยืนยัน เช่น http://localhost:3000/dashboard/ และ /dashboard/ บนโดเมนจริงใน Redirect URLs
- ใส่ NEXT_PUBLIC_SUPABASE_URL และ NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY ใน .env.local หรือ environment ของระบบ build แล้วเริ่ม dev server ใหม่ หรือ build และ deploy ใหม่

## โครงสร้าง

| ตำแหน่ง | หน้าที่ |
| --- | --- |
| `app/` | เส้นทางของแต่ละหน้า โครงหน้าหลัก และสไตล์ของเว็บ |
| `components/` | องค์ประกอบที่ใช้ร่วมกัน หน้ารายวิชา ตัวแก้ไขโค้ด ภาพรวมการเรียน ข้อสอบ และบัญชีอีเมล |
| `lib/content.ts` | ชนิดข้อมูลและเนื้อหาของรายวิชา บทเรียน โจทย์ และกรณีทดสอบ |
| `lib/evaluation.ts` | ตรวจคำตอบและเปรียบเทียบโค้ดกับรูปแบบเฉลย |
| `lib/progress.tsx` | บันทึกความก้าวหน้าและให้ XP |
| `lib/exam.ts` | คลังคำถามสำหรับข้อสอบฝึกทำ |
| `public/` | ฟอนต์ ใบอนุญาต และภาพประกอบ |

ตัวจำลอง Python เปรียบเทียบข้อความโค้ดกับรูปแบบเฉลยแล้วแสดงผลตัวอย่าง โดยไม่มีการประมวลผล Python จริง โค้ดที่ให้ผลเท่ากันแต่เขียนต่างจากเฉลยจึงอาจไม่ผ่าน อนาคตสามารถเชื่อมบริการประมวลผลภายนอกผ่านชนิดข้อมูลผลตรวจที่กำหนดไว้ได้

บทเรียนและข้อสอบจัดทำขึ้นเป็นสื่ออิสระสำหรับทบทวนด้วยตนเอง ภาพคอมพิวเตอร์สีม่วงบนกองหนังสือสร้างด้วย ImageGen และเก็บไว้ที่ `public/hero.webp` ใบอนุญาตฟอนต์อยู่ใน `public/fonts/` และในแพ็กเกจ Noto Sans Thai


ข้อสอบ ITDS113 ใช้เอกสารที่ผู้ใช้ให้เป็นขอบเขตเนื้อหา แม้ชื่อไฟล์บท 2–6 จะใช้รหัส ITDS125 ระบบจัดภายใต้ ITDS113 ตามที่ผู้ใช้ระบุ คำถามเป็นข้อสอบฝึกทำที่แต่งใหม่พร้อมคำอธิบายเฉลย คะแนนและคำตอบบันทึกแยกแต่ละบท
